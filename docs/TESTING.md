# فحص يدوي على الجوال

هذه الأشياء لا يمكن إثباتها إلا على جوال حقيقي (خصوصاً سامسونج). الاختبارات الآلية تغطي المنطق نفسه، وهذه القائمة تتأكد أن الجوال يتصرف كما نتوقع.

**للتجربة السريعة:** اجعل وقت التذكير بعد دقيقتين من الآن (**الإعدادات ← وقت التذكير**)، والإيقاع **يدوي** على **7** حتى يكون اليوم يوم تذكير.

| # | الخطوة | المتوقع | ✔︎ |
|---|---|---|---|
| 1 | أضف شخصين، واختر لكل منهما «آخر تواصل: قبل شهر تقريباً». | يظهر الأول في بطاقة اليوم. | |
| 2 | انتظر وقت التذكير والتطبيق مغلق. | يظهر إشعار «اطمئن على …» بثلاثة أزرار. | |
| 3 | اضغط **ليس اليوم** من الإشعار. | يتبدّل الاسم في الإشعار نفسه دون فتح التطبيق. | |
| 4 | اسحب الإشعار جانباً. | يعود خلال ثوانٍ. **(سجّل ما حدث على جوالك: هل سمح بالسحب؟ هل عاد؟)** | |
| 5 | أعد تشغيل الجوال. | يعود الإشعار بعد الإقلاع (قد يستغرق دقيقة). | |
| 6 | اضغط **واتساب** من الإشعار. | تفتح محادثة الشخص، ويختفي الإشعار، ويظهر التواصل في صفحته. | |
| 7 | افتح التطبيق بعد الرجوع من واتساب. | يسألك «خيط؟». | |
| 8 | من بطاقة اليوم اضغط **واتساب** ثم **تراجع**. | يُسجَّل التواصل ثم يُحذف. | |
| 9 | اجعل بداية الهدوء الليلي بعد دقيقة، والإشعار ظاهر. | يختفي الإشعار عند بدايتها. | |
| 10 | صدّر نسخة احتياطية، امسح كل البيانات، ثم استورد الملف. | تعود البيانات والإعدادات كاملة. | |
| 11 | أضف الويدجت واضغط زر **واتساب** فيها. | تفتح المحادثة ويُسجَّل التواصل. | |

> ملاحظة عن البند 4: أندرويد 14 وما بعده يسمح للمستخدم بسحب الإشعارات الثابتة. التطبيق يعيد نشره فور السحب. لم يُختبر هذا على جوال سامسونج حقيقي أثناء التطوير، فنتيجتك هنا هي المرجع.
